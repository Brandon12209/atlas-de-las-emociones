# Evidencia de las cinco salas

Integración verificada el 8 de noviembre de 2026. Los renders de origen se obtuvieron de las copias Blender; las capturas web corresponden a Chrome con Three.js. Son capturas y renders de los modelos de origen.

- `source-integrity.json`: originales y copias protegidas con sus huellas SHA-256, recursos finales y prueba de que Felicidad conserva su GLB anterior.
- `browser-audit.json`: piezas, texturas, límites espaciales y errores registrados al abrir los cuatro modelos nuevos.
- Cada carpeta de emoción contiene nueve comparativas, mediciones, cámaras, manifiesto de geometría, doce vistas de rotación y ejemplos del panel contextual.
- `test-results.json`: diez pruebas de producción aprobadas, sin pruebas omitidas ni reintentos que oculten fallos.
- `multipage-validation.json`: nueve páginas a 1440 y 390 píxeles; comprobaciones de texto, enlaces, errores y accesibilidad automática.
- `responsive-extra.json`: las nueve páginas a 820 y 1024 píxeles, sin desbordamiento horizontal ni recursos HTTP fallidos en las visitas comprobadas.
- `collection-desktop.png`, `collection-mobile.png`, `region-mobile.png`, `exhibit-desktop.png` y `rubric-desktop.png`: presentación real y lectura contextual.

Las medidas comparan el personaje, excluyendo el fondo. La diferencia RGB se calcula en la intersección de las máscaras alpha. Las láminas incluyen diferencia ×3 para hacer visibles residuos de filtrado, sombras, transparencias y bordes; no se usan las métricas como un porcentaje de perfección artística.

Metodología y limitaciones: [integración de cinco emociones](../../INTEGRACION_CINCO_EMOCIONES.md). Trazabilidad curricular y científica: [rúbrica y fuentes](../../RUBRICA_Y_FUENTES.md). La evidencia histórica de Felicidad permanece en la carpeta superior.
